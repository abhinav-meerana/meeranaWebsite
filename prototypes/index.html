How to read these pages

  • Proposed copy, with sources. Each claim carries data-ev="EV-###", which points to plan/03-evidence-register.csv. Dashed "Prototype note" boxes mark open decisions.
  • Sample data is labelled. Every number inside an "Illustrative interface" frame is sample data. No accuracy, latency or uptime figures are claimed.
  • Tokens under test. Each page inlines .claude/skills/ui-system/references/tokens.css, so the prototypes also exercise the token file and its 64 verified contrast pairs.
  • Motion. There is one signature motion per page. The OS reduced-motion setting is respected. Loops have a visible pause control (WCAG 2.2.2). Scrolling is native: no prototype needs Lenis, which DD-02 allows only on yisbir.com.
  • Logos. Official rasters are shown at or below native size, in other colourways via CSS masks (DD-09). Swap in the vector masters when they arrive.

Rebuilding

Templates and generators are in prototypes/src/. Run python prototypes/src/build.py (needs Python with Pillow, and Node). The Y1 scene (y1_scene.js) and the Y2 sample index (y2_index.js) run both in the page and at build time, so the static frames always match the live ones.

Checks: python .claude/skills/anti-generic-audit/scripts/audit_page.py <file> --brand meerana|yisbir --strict and python .claude/skills/web-animations/scripts/motion_lint.py <file>.

Production target: Next.js, Tailwind CSS v4 and shadcn/ui, following the six skills in .claude/skills/. These HTML files are design references, not production code.
