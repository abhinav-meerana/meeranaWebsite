# React Bits components — licence notice

`ColorBends.tsx`, `DotField.tsx`, `PillNav.tsx` and `OptionWheel.tsx` in this
folder are adapted from **React Bits** (https://reactbits.dev,
https://github.com/DavidHDev/react-bits, TypeScript + CSS registry builds,
retrieved 2026-10-12; PillNav 2026-10-13, replacing the earlier CardNav). Each file's header lists exactly what was changed.
The word-level blur in the homepage story and the tilt on the platform panels
are re-implementations of the ideas behind React Bits' *BlurText* and
*TiltedCard*, written for GSAP and CSS, because the originals depend on
`motion`, which this project does not use.
